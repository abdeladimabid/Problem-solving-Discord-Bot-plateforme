# Veille topics of earlier promotions — inspiration only

> **Source:** the veille programme of an earlier promotion (topics only, no names).
> **Used by:** `src/shared/activities.ts` (`INSPIRATION`), which must stay identical to this file (a test checks it).
> **Rule:** these topics are **ideas**, never mandatory. The AI only sees the topics of the week's technologies (from the
> programme: `techOfWeek`) and may use, reword or ignore them. The **programme** of the week stays the only scope:
> a topic of a later week is never proposed. The "Culture" topics fit any week, for the lighter last day of a week.
> Topics outside the DWWM programme (blockchain, Web 3.0, zero-knowledge proofs, Salesforce, ServiceNow, WordPress,
> htmx, microservices, message brokers…) were left out.
>
> Each heading is the name of a technology of the programme (`TECHS` in `src/shared/program.ts`).
